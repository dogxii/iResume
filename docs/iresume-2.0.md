# iResume 2.0

iResume 2.0 的目标不是增加一层更重的应用框架，而是把现有工作台升级为可扩展的简历文档引擎。产品继续保持轻量、本地优先、打印可控和云同步可选。

## 架构原则

1. 布局与主题色分离。布局决定信息结构，主题色属于文档外观。
2. 文档能力与界面组件分离。规范化、历史和持久化不再由 `App.tsx` 管理。
3. 模板通过注册表接入。特殊模板可以拥有独立渲染器，不向通用预览继续增加布局分支。
4. 大型数据使用 IndexedDB。LocalStorage 只保存缩放、视图等轻量界面偏好。
5. AI 和导入能力通过适配器接入，不直接依赖核心文档结构。

## 实施阶段

### Alpha 1：基础层

- 版本化 Workspace
- IndexedDB 仓库
- 自动撤销与重做
- 完整文档快照
- 模板注册表
- 核心单元测试
- 侧栏式简历库与模板中心
- 简历和模板的响应式 A4 预览
- 从模板快速创建简历

### Alpha 2：文档模型

- 可扩展分区与自定义字段
- 稳定的字符串 ID
- 内容、外观和编辑状态分层
- 统一的导入、导出规范

### Beta：编辑工作台

- 内容、样式、预览三种明确模式
- 面向移动端的模式切换
- 受约束的富文本编辑
- 字段显示、排序与自定义名称
- 一页紧凑度优化

### 2.0 正式版

- 模板视觉回归与打印回归
- Markdown 导入和导出
- 中英文界面
- 可选的 BYOK AI 润色与语法检查

## 数据兼容

2.0 使用新的 Workspace 数据边界，不读取 1.x 的 LocalStorage 简历库。旧数据键不会主动删除，避免升级过程破坏用户仍保留的 1.x 数据。
